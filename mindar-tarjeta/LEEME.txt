INICIO RAPIDO: TARJETA AR CON MINDAR

1. Prepara la imagen del frente de tu tarjeta como JPG o PNG. Usa la imagen final impresa, sin perspectiva ni filtros. Debe tener detalles visuales distribuidos por toda la superficie.
2. Abre el compilador de objetivos de MindAR: https://hiukim.github.io/mind-ar-js-doc/tools/compile
3. Carga la imagen, pulsa Start y revisa que los puntos detectados cubran bien la tarjeta. Descarga el resultado .mind.
4. Crea la carpeta assets junto a index.html. Guarda allí el archivo .mind y asegúrate de que el nombre coincida exactamente con la ruta declarada en index.html. El ejemplo no necesita la imagen JPG para funcionar.
5. Para probar, sirve la carpeta con un servidor local (por ejemplo, la extensión Live Server de VS Code) y abre la URL localhost. No abras index.html con doble clic.
6. Para probar desde un teléfono, publica la carpeta en un alojamiento con HTTPS y abre la URL allí. El navegador pedirá permiso para la cámara.

PROGRAMACION
- Cambia los textos de los elementos <a-text> en index.html.
- Puedes agregar una imagen con <a-image src="#mi-imagen" ...> y declararla dentro de <a-assets>.
- Puedes agregar un modelo GLB con <a-asset-item id="modelo" src="./assets/modelo.glb"></a-asset-item> en a-assets y <a-gltf-model src="#modelo" scale="0.1 0.1 0.1" position="0 0 0.1"></a-gltf-model> dentro del elemento mindar-image-target. Ajusta la escala al modelo.
- Si compilas varios objetivos, conserva el orden de las imágenes y usa targetIndex 0, 1, 2... para anclarlos.

IMPORTANTE
- La cámara requiere permiso y un contexto seguro: localhost durante desarrollo o HTTPS al publicar.
- El ejemplo usa MindAR 1.2.5 y A-Frame 1.5.0 desde CDN; para despliegue estable, se pueden descargar/servir localmente esas dependencias.
- La ubicación y tamaño del contenido dependen de la proporción de la imagen objetivo. Prueba con la tarjeta impresa real.
