# Tarjeta AR con MindAR

La experiencia está en `mindar-tarjeta/`. La portada raíz redirige allí para que GitHub Pages pueda publicar el repositorio desde la raíz.

## Publicar con GitHub Pages

1. Sube todo el contenido del repositorio conservando la estructura de carpetas.
2. En el repositorio, abre **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**, luego la rama `main` y la carpeta `/(root)`.
4. Guarda y espera a que GitHub Pages termine el despliegue.

La URL del proyecto tendrá el formato `https://USUARIO.github.io/REPOSITORIO/`. La portada llevará a `mindar-tarjeta/`.
